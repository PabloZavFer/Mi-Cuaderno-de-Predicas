# Política de privacidad de «Mi Cuaderno de Prédicas»

*Última actualización: [fecha de publicación]*

«Mi Cuaderno de Prédicas» es una aplicación gratuita desarrollada por [tu nombre]. Esta política explica cómo
trata la información.

## Información que se recopila

**Ninguna.** La aplicación no recopila, no transmite y no vende datos personales. No requiere cuenta,
no muestra anuncios, no incluye herramientas de análisis ni de seguimiento y no solicita permisos del dispositivo.

## Dónde se guarda tu contenido

Las prédicas, notas y ajustes se guardan solo en tu dispositivo. Si tienes activada la copia de seguridad de
Android, el sistema puede incluir los datos de la app en tu copia de seguridad personal de Google, según tu
configuración.

## Archivos que tú exportas

Cuando exportas un PDF, compartes una prédica como texto o creas un respaldo en JSON, el archivo se guarda o se
envía únicamente donde tú elijas. La aplicación no tiene acceso a esos destinos.

## Enlace de donación

Si tocas «Donar», se abre una página externa en tu navegador. Esa página pertenece a un proveedor de pagos
externo y se rige por su propia política de privacidad. La aplicación no recibe ni guarda datos de pago.
